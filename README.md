### 🔥 Overview  
This project analyzes LEGO sets data (from 1970 onwards) to uncover insights on **pricing, themes, age groups, and product complexity** using an interactive Power BI dashboard.

---

### 📈 Key Insights  
- 🧱 Few theme groups dominate most LEGO sets  
- 💰 Higher price = more pieces (complex sets)  
- 👶 Most products target mid-age groups  
- 🎯 Premium sets are fewer but detailed  

---

### 🛠️ Tools & Technologies  
- Power BI  
- Power Query (ETL)  
- DAX (Measures & Calculations)  
- Data Modeling  

---

### ⚙️ What I Implemented  
- Data cleaning (remove nulls, change data types)  
- Created **Age Range & Price Range columns**  
- Built KPI measures using DAX  
- Used `HASONEVALUE` for dynamic visuals  
- Created **What-if parameter (Max Price filter)**  
- Designed **custom image tooltip**  
- Added **Decomposition Tree (AI visual)**  
- Implemented **Page Navigation (Set Explorer)**  

---

### 📊 Dashboard Features  
- Interactive slicers  
- KPI cards  
- Dynamic filtering  
- Image-based insights  
- Clean & user-friendly UI  

---

### 🚀 Outcome  
This dashboard helps analyze **product trends, pricing strategy, and theme performance**, enabling better data-driven decisions.
